# 규칙: 실제로 이렇게 진행했어요

2026년 10월 24일 Ambition for Korea에서 참가자에게 공지하고 그대로 운영한 규칙이에요. 전날 밤 디스코드 공지가 기준이었고, 당일에 바뀐 부분은 아래에 따로 적었어요. 이 키트의 화면과 서버는 이 규칙을 그대로 강제하도록 만들어져 있어요.

## 한 줄 요약

**하루 만에, 새 공개 레포에서, 팀당 한 번만 내고, 낸 순서대로 VC가 바로 심사한다. 먼저 3표가 모인 쪽으로 결과가 정해지고, 본선 8자리가 차면 문이 닫힌다.**

## 참가와 팀

- 2~4인 팀. 1인 팀은 받지 않았어요.
- 신청서와 GitHub·LinkedIn을 보고 선발했어요 (960명 신청, 105명 선발, 41팀).
- 디스코드 닉네임은 실명으로 바꿔 달라고 했어요. 결과가 팀 이름과 팀원 이름으로 발표되기 때문이에요.

## 자원: 모두 같은 크레딧으로

- 참가자 한 명당 Claude 크레딧 $500. Claude Code와 배포한 앱의 API 호출에 모두 쓸 수 있고, 팀원끼리 한 조직에 모아 써도 돼요.
- 개발과 서비스의 AI 기능은 **Claude로만** 만들어요. 다른 회사 LLM이나 개인 서버 모델 API는 쓰지 않아요.
- 음성·이미지 변환처럼 Claude가 직접 못 하는 일은 외부 API를 써도 되지만, 판단과 생성 같은 핵심 AI 기능은 Claude로 만들어요 (당일 10:41 질문에 10:45 답).
- 디자인·영상 같은 주변 도구는 자유롭게 쓰되 비용은 각자 부담이에요.
- 상금은 없었어요. 결선 팀은 VC와 후속 미팅으로 이어져요. 당일 아침 Anthropic이 결선 8팀에 팀당 Claude 크레딧 $5,000을 추가하기로 했어요.

## 주제: VC가 직접 낸 미션

- VC 여섯 곳이 미션 9개를 냈고, 당일 09:40쯤 무대에서 한 장씩 공개했어요. 미리 준비해 올 수 없게 하려는 거예요.
- 미션 대신 **와일드카드**(우리 팀 아이디어)를 고를 수 있어요. 대신 타깃 해외 시장을 나라와 고객까지 적어야 하고, VC가 낸 주제가 아니라 덜 유리할 수 있다고 미리 알렸어요.
- 주제 선언에는 미션, 아이디어 한 줄, 타깃 해외 시장, 공개 GitHub 레포를 넣어요. 팀에서 한 명만 하면 되고, **선언한 뒤에는 바꿀 수 없어요.**

## 당일 코드만

- 기획과 개발은 현장에서 시작해요. 코드는 **10:00 이후 새로 만든 공개 레포**에서만 쓰고, 커밋은 main에 push해요.
- 모든 팀의 커밋 기록이 현장 LED에 공개돼요.
- 레포를 전부 공개로 한 이유를 전날 밤 이렇게 적었어요.
  > 아이디어는 귀하지만 공공재예요. 숨긴다고 지켜지지 않고, 꺼내 놓는 순간 더 빨리 앞으로 갑니다. 결국 남는 건 실행과 속도예요.
- 공개된 오픈소스는 써도 돼요. 단, **포크하지 말고** 새 레포에 가져와 README에 출처를 적어요. 포크하면 원래 프로젝트의 예전 커밋이 딸려 와서 '10시 전 커밋'으로 표시돼요 (당일 10:13 공지).
- 팀이 미리 만들어 둔 자기 코드는 쓸 수 없어요. 기존 코드를 일부 가져왔다면 제출할 때 직접 표시해요.
- **API 키는 절대 커밋하지 않아요.** 공개 레포에 올라간 키는 몇 분 안에 털려요.

## 제출: 팀당 한 번

- 10:00부터 17:00까지, 같은 제출 페이지에서 해요.
- 제출할 것: 서비스 이름, 한 줄 소개, 타깃 해외 시장, 데모 링크, **데모 사용법**(VC가 무엇부터 눌러 보면 되는지, 테스트 계정), 발표자료 PDF 2장 이내, 오늘 새로 만든 부분 한 줄.
- 한 번 내면 다시 낼 수 없어요. 제출 순간의 커밋으로 심사해요.
- 앱은 최소 21시까지 켜 두기로 했어요. VC가 데모를 직접 열어 써 보기 때문이에요.

## 심사: 먼저 3표

- 제출한 순서대로 VC 여섯 곳의 심사 화면에 올라가요. VC는 각자 노트북으로 데모를 써 보고 발표자료를 본 뒤 PASS나 FAIL을 눌러요.
- 기준은 하나예요. **"이 팀과 후속 미팅을 하고 싶은가?"**
- 표는 들어온 순서대로 세요. **먼저 PASS 3표가 모이면 본선, 먼저 FAIL 3표가 모이면 탈락**이에요. 보통 다섯 번째 표 안에 확정되고, 3:3은 생기지 않아요. 확정 뒤에 들어오는 표는 막혀요.
- 결과는 현장 LED와 디스코드에 자동으로 발표돼요. 탈락은 결정되는 즉시 나가고, 본선은 제출 순서대로 나가요. 뒤 팀이 먼저 3표를 받아도 앞 팀 결과가 나올 때까지 LED에서 "발표 대기"로 기다려요.
- VC는 아직 결과가 안 난 팀 중 제출이 빠른 3팀까지만 판단할 수 있어요. 그 아래 팀은 내용만 볼 수 있고 "순서 대기"로 보여요. 이미 낸 판단은 결정 전까지 고칠 수 있어요.
- **본선 8자리가 차는 순간 마감**이에요. 그 뒤에 낸 팀은 심사를 받지 못해요. 그래서 준비되면 먼저 내는 게 유리하지만, 덜 된 채로 냈다가 탈락하면 끝이에요.
- VC는 한 줄 평(선택)과 메모(선택)를 남겨요. 한 줄 평은 VC 이름 없이 공개되고, 메모는 운영진만 봐요.
- 심사 중에는 어떤 VC가 어떤 판단을 했는지 팀에게 보이지 않아요.

## 샤크탱크: 투자가 아니라 다음 미팅

- 19:00부터 본선 8팀이 본선에 오른 순서대로 무대에 서요. **발표 3분(영어) + 질의응답 7분(한국어)**, 각자 노트북으로 발표하고 데모해요.
- 질의응답이 끝나면 VC가 심사 화면에서 '만나고 싶어요'나 '패스'를 눌러요. 손을 든 VC 로고가 LED에 한꺼번에 뜨고, 여러 곳이면 팀이 한 곳을 골라요.
- 본선 팀은 팀원 모두 현장에 있어야 했어요.
